## 公開プロジェクト

- [secret-base](https://github.com/kaopuuu-hash/secret-base) — 個人制作の実験サイト。レトロな管理人ページと、仮想街いわた等の公開オープンデータ分析ページ（[公開サイト](https://kaopuuu-hash.github.io/secret-base/)）
- [iwata-open-data-analysis](https://github.com/kaopuuu-hash/iwata-open-data-analysis) — 仮想街いわたの公開オープンデータによる地域分析。テーマ15選＋統合・将来シナリオのレポート、ダッシュボード、GISマップとテーマ別深掘り
- [iwata-open-data-themes](https://github.com/kaopuuu-hash/iwata-open-data-themes) — 仮想街いわたの公開オープンデータを17テーマに分けて、グラフ・表・GIS地図で掲載するページ集
